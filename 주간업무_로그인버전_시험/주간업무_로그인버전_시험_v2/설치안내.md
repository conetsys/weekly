# 주간 업무 · 로그인 버전 — 시험 설치 순서

지금 쓰는 고객품질팀 화면(GitHub 저장소)은 **그대로 두고**, 새 저장소에 시험용으로 올립니다.
같은 Supabase 프로젝트를 쓰지만 새 표(wk_…)를 따로 만들어서 지금 데이터에는 영향이 없어요.

## 1. Supabase 표 만들기 (SQL Editor)
1. Supabase 대시보드 → 왼쪽 **SQL Editor** → **New query**
2. `supabase/1-schema.sql` 전체를 붙여넣고 **Run**
3. 새 query에 `supabase/2-first-admin.sql` 을 붙여넣고, `관리자메일@회사.com` 과 `관리자이름` 을 본인 것으로 바꾼 뒤 **Run**

## 2. 로그인 서버 함수 올리기 (Edge Functions)
1. 왼쪽 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 함수 이름: **wk-auth** (정확히 이 이름)
3. 편집기 내용을 모두 지우고 `supabase/functions/wk-auth/index.ts` 전체를 붙여넣기 → **Deploy**
4. 올라간 wk-auth 함수 → **Details(설정)** → **Enforce JWT verification(Verify JWT)** 를 **끄고** 저장
5. 왼쪽 **Edge Functions → Secrets** → **Add new secret**
   - Name: `PIN_SECRET`
   - Value: 길고 아무도 모르는 문자열 (30자 이상). **한 번 정하면 바꾸지 마세요.** 바꾸면 모두 비밀번호를 다시 정해야 해요.

## 3. 가입 막기 (권장)
**Authentication → Sign In / Providers** → **Allow new users to sign up** 끄기
(사람 등록은 관리 화면에서만 하므로 꺼도 됩니다. Email 로그인 자체는 켜 둔 상태여야 해요.)

## 4. 화면 올리기 (새 GitHub 저장소)
1. GitHub에서 **새 저장소** 만들기 (예: `weekly-login-test`) — 지금 쓰는 저장소에 올리지 마세요
2. `web` 폴더 안 파일 7개를 모두 업로드 → Commit
3. Settings → Pages → Branch `main` / `(root)` → Save → 1~2분 뒤 주소로 접속

## 5. 처음 설정
1. 관리자 메일 + **0426** 으로 로그인 → 숫자 6자리로 바꾸기
2. 오른쪽 위 **관리 → 팀** : 필요한 팀 만들기 (고객품질팀은 이미 있음)
3. **관리 → 사람** : 엑셀에서 `메일 / 이름 / 소속 / 역할` 4칸을 복사해 붙여넣기 → 미리보기 → 등록하기
   - 이름은 지금 화면의 담당자 이름과 똑같이 (그래야 기존 업무가 연결돼요)
4. **관리 → 팀 → 고객품질팀 → 지금 쓰는 화면의 업무 가져오기** → 미리 확인 → 가져오기
5. 팀원 1~2명에게 주소를 알려주고 시험 (첫 비밀번호 0426)

## 바꾸기 전에 알아둘 것
- 시험 기간에 지금 화면에 쓴 업무는 마지막에 **'이 팀 업무를 비우고 다시 가져오기'**로 한 번 더 옮기면 돼요.
- 등록 담당자 지정: 관리 → 사람 → 그 사람 **수정** → '등록 담당자' 체크 (관리자만 가능)
- 비밀번호 잊음: 관리 → 사람 → **0426 초기화**
