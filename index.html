처음이세요? 비밀번호 0426

처음엔 0426 네 자리만 넣고 로그인하세요. 이어서 나만 아는 숫자 6자리로 바꾸는 화면이 나와요. 비밀번호를 잊었으면 등록 담당자에게 초기화를 요청하세요.

새 비밀번호 정하기

  • 같은 숫자만 반복(111111)은 안 돼요
  • 123456, 987654처럼 이어지는 숫자는 안 돼요
  • 0426으로 시작하는 번호는 안 돼요

관리

📲 앱으로 설치하기

설치하면 바탕화면이나 홈 화면의 아이콘으로 바로 열려요. 주소창 없이 앱처럼 쓸 수 있어요.

  1. 크롬이나 엣지로 이 주소를 열어요.
  2. 주소창 오른쪽 끝의 설치 아이콘(모니터에 화살표 모양 ⊕)을 눌러요.
  3. 아이콘이 안 보이면 오른쪽 위 ⋮(엣지는 …) 메뉴 → 전송, 저장 및 공유 → 페이지를 앱으로 설치 (엣지: 앱 → 이 사이트를 앱으로 설치)
  4. 설치를 누르면 바탕화면과 시작 메뉴에 '주간업무' 아이콘이 생겨요.
휴대폰으로 열기

휴대폰 카메라로 이 QR을 찍으면 이 주소가 바로 열려요. 거기서 안드로이드·아이폰 방법대로 설치하세요.

  1. 크롬으로 이 주소를 열어요.
  2. 오른쪽 위 ⋮ 메뉴를 눌러요.
  3. 앱 설치 또는 홈 화면에 추가를 누르고 설치를 눌러요.
  4. 홈 화면에 '주간업무' 아이콘이 생겨요.

삼성 인터넷을 쓰면: 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

  1. 사파리로 이 주소를 열어요. (카카오톡 안에서 열렸다면 오른쪽 아래 나침반 버튼으로 사파리에서 열기)
  2. 아래쪽 가운데 공유 버튼(네모에서 위로 화살표 ⬆)을 눌러요.
  3. 목록을 아래로 내려 홈 화면에 추가를 눌러요.
  4. 오른쪽 위 추가를 누르면 홈 화면에 '주간업무' 아이콘이 생겨요.

아이폰은 '지금 설치하기' 버튼을 쓸 수 없어서 위 순서로만 설치할 수 있어요.
